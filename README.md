#### 🔍 [Google Search for Roku TV](https://github.com/RokuProducts/google_search)
- **Tech Stack**: Django, MySQL, AWS S3, CI/CD, GitHub Actions

#### 🧠 [Crosswords Game for Roku](https://github.com/RokuProducts/crosswords-backend)
